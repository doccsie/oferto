О сервисе

Оферто — инструмент для компаний, которые работают с внештатными исполнителями: самозанятыми, ИП и физлицами. Мы автоматизируем самую нудную часть — подготовку типовых документов.

Данные не покидают браузер

Реестр обрабатывается прямо на вашем компьютере. Паспортные данные и реквизиты не загружаются ни на какой сервер — у нас его попросту нет.

Юридически выверенный шаблон

Договор-оферта возмездного оказания услуг с заданием, актом и анкетой исполнителя. Подходит для самозанятых, ИП и физлиц, в том числе иностранных.

Любой размер реестра

Два исполнителя или двести — договоры формируются пакетом за секунды, каждый файл назван по ФИО исполнителя.

Прозрачный формат

Обычная таблица Excel с понятными колонками. Пример файла с подсказками-плейсхолдерами можно скачать в личном кабинете.

Какие данные нужны

Одна строка таблицы — один исполнитель. Колонки распознаются по названиям, порядок не важен.
